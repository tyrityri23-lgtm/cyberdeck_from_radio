# cyberdeck
ok guys so i finally finished all the designing for my crazy cyberdeck project but i havent actually built it in real life yet because i still need to buy the parts and put it all together. i spent literally forever designing the whole case in freecad and making sure everything is perfect and i even exported a step model of my custom pcb so i know it will actually fit inside without smashing together when i screw it shut. the main brain that is gonna run everything is the radxa x4 sbc and it is super fast because it uses x86 architecture so it can run normal pc stuff without lagging like a normal raspberry pi would.

for the typing part i designed a completely custom keyboard matrix and routed it all out using an esp32 c3 chip and this mcp23017 io expander thing so i can wire up all the keys whenever i actually sit down to solder it. i also added some extra switches to the pcb design just in case i wanna add some random stuff later and the absolute best part is that i put a gyroscope on the board so i can program an anti theft alarm so if my friends try to touch my deck it will go totally crazy. im gonna mount a really sick screen inside this old radio chassis so it looks exactly like a real hacker terminal when its finally done.

even though all the files and the 3d models and the schematic are completely finished right now i still need to figure out some code for the power management so the batteries dont overheat when i actually build it. im only thirteen so figuring out how to make the radio chassis communicate with the sbc is probably gonna be super stressful but ill figure it out when i start putting the physical pieces together. anyway all the final design files and the 3d models for the case are uploaded in the folders here so you can download them and look at them while i try to get the stuff to actually build this thing so yeah bye.<img width="1183" height="815" alt="Screenshot 2026-07-18 144718" src="https://github.com/user-attachments/assets/80e58209-4339-4b1a-bf22-60b36fc74f64" />
